SkillSwap

SkillSwap is a real-time skill-sharing and collaboration platform where users can connect, chat, and exchange knowledge or services. It provides a Messenger-like chat interface, project posting feature, and secure authentication.

🚀 Features

🔐 Secure Authentication

JWT-based login and signup system

User profile management

💬 Real-time Chat

WebSocket-powered instant messaging

Online/typing status

Messenger-like UI (contacts sidebar + active chat view)

📌 Project Posting

Share project details and collaborate

Filter and search projects by category

⚡ Fast & Modern Stack

Backend: FastAPI + Neon Serverless PostgreSQL

Frontend: React + Bootstrap (Messenger-like design)

WebSockets: Real-time communication

🛠️ Tech Stack

Frontend: React, Bootstrap, WebSockets

Backend: FastAPI, SQLAlchemy, JWT Auth

Database: Neon Serverless PostgreSQL
